# Changelog
All notable changes to this package will be documented in this file.

## [0.1.0] - 2026-06-28

### Added
- First release of **PrefHub** — an editor window to view, edit, add, and delete the project's PlayerPrefs.
- Cross-platform key discovery (macOS preference domain, Windows registry) with a graceful fallback.
- Inline value/type editing, add/update bar, single-key and Delete All removal, and live search.
